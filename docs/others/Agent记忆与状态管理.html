Short-term Memory

上下文窗口管理的四种策略

全窗口回放

完整历史 → 模型

适合：短对话 · 简单任务 风险：Token 溢出 · 成本不可控

滑动窗口

保留最近 N 轮

适合：闲聊 · 低上下文依赖 风险：丢失关键早期信息

Token 预算分配

按类别分配 Token 配额

适合：企业级 Agent 风险：分配比例需调优

摘要压缩

旧对话 → 结构化摘要

适合：长对话 · 多轮交互 风险：信息损失 · 摘要幻觉
推荐 Token 预算
系统策略 15% 当前任务 20% 近期对话 25% 检索记忆 25% 工具结果 15%

Retrieval Scoring

五信号加权检索评分公式

S(m,q) = wr·R + wt·T + wi·I + wc·C + wp·P
R

相关性

语义 + 关键词匹配

T

时效性

指数衰减 · 越新越优先

I

重要性

事件权重 · 决策影响度

C

置信度

P

策略兼容

近期传闻不应仅因更新就超越旧的权威记录——置信度和来源同样重要

Long-running Tasks

长时程任务状态管理九原则

1追加有意义事件，不修改历史
2每步检查点，允许任意位置恢复
3稳定运行 ID，跨进程生命周期
4外部化大型产出物，状态只存引用
5审批边界安全暂停，不阻塞资源
6调度唤醒与重试，不轮询等待
7记录截止日期与租约，防止僵尸任务
8工具调用结果可恢复，不重复执行
9运维人员可检查与手动重放

Consistency Model

高风险系统应保留冲突并要求裁决

强一致性

金融 · 权限 · 立即可见

适用：资金操作 · 权限变更

读己所写

Agent 自身更新立即可见

适用：工作记忆 · 决策记录

最终一致性

低风险 · 允许短暂不一致

适用：协作知识 · 共享偏好

冲突保留

不确定事实保留所有版本

适用：多源矛盾 · 需要裁决

静默"最后写入者获胜"在 Agent 系统中是危险的——保留冲突比静默覆盖安全
