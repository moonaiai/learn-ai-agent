核心结论

三个核心结论

01 Benchmark 高分是幻觉 — 生产成功率仅 56.6%，污染率高达 94%
02 可靠性 ≠ 能力 — pass@3=97% 但 pass^3=34%，评测可靠性而非能力
03 评测是工程, 不是一次性测试 — 从生产提取、持续回灌、多维度覆盖
