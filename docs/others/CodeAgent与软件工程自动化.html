Hooks Mechanism

Hooks：Claude Code 的差异化治理能力

PreToolUse

工具执行前拦截 · 可阻止危险操作

PostToolUse

工具执行后触发 · 自动格式化/lint

SessionStart

会话开始时 · 加载环境/检查依赖

SessionEnd

会话结束时 · 清理/审计日志

Core Judgment

核心判断

Claude Code核心竞争力 = 代理工作流深度 + 仓库级推理
Codex核心竞争力 = 执行环境 + 模型服务 + 云端任务的统一

Code Agent 已从"能不能写代码"进化到
"能不能安全、高效、可控地接管工程任务"

两者都应被当作受权限和测试约束的自动化系统，
而非可以直接获得生产权限的自主工程师
