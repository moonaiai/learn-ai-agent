Copilot Code Review 多 Agent 审查架构

已确认发布

Copilot Code Review 的多 Agent 合奏架构是目前最直接的对标对象。Lite 档位引入多个并行 Agent 后，高严重度问题采纳率提升 47%，而成本反降 8%——证明并行多角度审查比单一 prompt 更优。企业三档权限模型（Deny/Ask/Allow 覆盖 Shell、文件读写、网络四类）的交集语义设计值得你的 AICR 直接借鉴。Auto-resolve 在后续 commit 解决问题后自动关闭评论，减少人工清理负担。

对标差距：多角度并行审查

你的 AICR 目前是单一 LLM 调用（即使 harness 编排了 10 步工具链，判断环节仍是一次调用）。Copilot 将审查拆分为多个专注角色的 Agent 并行执行，各自只关注一个维度（安全、逻辑、风格），最后汇总去重。这种方式在相同成本下显著提高了召回率。你的 harness 架构天然支持这种并行调用——只需在判断环节分拆为多个并行 LLM 请求，用不同的 system prompt 分别聚焦安全规则、逻辑缺陷、风格规范，然后在 harness 层做结果合并与去重。

P0 落地建议

多角度并行审查（2-3 周）：在 harness 判断环节增加 2-3 个并行 LLM 请求，各用不同 system prompt 聚焦一个维度。合并层做去重 + 严重等级排序。预期效果：高严重度问题采纳率提升 30-50%。依赖：无外部依赖，纯内部改造。
